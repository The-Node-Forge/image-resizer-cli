# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/The-Node-Forge/image-resizer-cli/security/advisories/new)
for this repository and include steps to reproduce.

## Supported Versions

Only the latest published release of `@the-node-forge/image-resizer-cli` receives
security fixes.
